Materiales pedagógicos gratuitos para trabajar las sagas Valentina Roca y Calan Kennett en el aula.

¿Buscas lecturas recomendadas secundaria para tus alumnos? Las sagas de David Mateos son ideales. Aquí encontrarás una guía didáctica PDF para cada título, con actividades para trabajar el libro en clase adaptadas a ESO y Primaria.
